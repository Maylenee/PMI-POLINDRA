3.2. Soft File Laporan PMI 
Pada sub bab ini dibahas mengenai format penamaan file beserta jenis file yang 
diunggah ke laman resmi PMI. 
3.2.1. Penamaan File 
1. Penamaan file dokumen diawali dengan nim dan dilanjutkan dengan nama 
lengkap mahasiswa (huruf pertama kapital). 
2. Nama file tidak mengandung spasi, tetapi menggunakan tanda hubung 
underscore. 
3. Penamaan project (aplikasi atau hasil lainnya ) disesuaikan dengan nama 
aslinya dan disesuaikan dengan poin nomor 2. 
3.2.2. Jenis File 
1. Jenis dokumen terbagi menjadi dua format, yaitu *.docx dan *.pdf. 
2. Laporan PMI disajikan ke dalam satu file *.docx (tidak dipisah per bab atau per 
bagian lainnya)  
3. Isi dan nama file laporan PMI dari jenis file *.docx dan *.pdf harus sama. 
4. Project harus di-compress ke dalam format *.zip.
